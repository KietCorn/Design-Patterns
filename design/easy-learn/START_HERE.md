## 🔍 Cách đọc từng file

### Step 1: VẤN ĐỀ
**Dừng lại, hỏi bản thân**: "Tôi gặp vấn đề này rồi không?"

### Step 2: IDEA
**Bỏ code**, chỉ đọc từ. Hiểu ý tưởng.

### Step 3: DIAGRAM
**Vẽ lại** bằng tay (vào giấy, OneNote, v.v). Không copy.

### Step 4: NHỚ NHÉ
**Ghi ra 1 câu** để nhớ pattern này.

### Step 5: VS PATTERN KHÁC
**So sánh**: Cái này khác cái kia sao?

### Step 6: CODE
**Lúc này mới đọc code**. Giải thích code bằng concept bạn đã hiểu.

## 💬 Câu hỏi thường gặp

**Q: Mình nên đọc pattern 1, 2, 3 cùng lúc hay lần lượt?**  
A: **Lần lượt**. Học pattern 1 → hiểu rõ → chuyển pattern 2. Không học song song.

**Q: Tôi nên code theo dõi không?**  
A: Không bây giờ. Chỉ đọc code, hiểu nó. Tự viết code vào **week sau**.

**Q: Phải học code Python/JS không?**  
A: Không. Code chỉ để **show concept**. Bạn hiểu concept → apply vào bất kỳ ngôn ngữ.

**Q: Mình không hiểu Builder?**  
A: Quay lại "IDEA", bỏ code. Builder = set từng bước, rồi build(). Xong rồi đọc code.
