# 🎓 Design Patterns - Cách Học Dễ Hiểu

## Cách đọc mỗi pattern

Mỗi pattern được viết với cấu trúc này:

### 1️⃣ **VẤN ĐỀ** 
> Cái gì mà bạn gặp phải trong code thực tế

### 2️⃣ **IDEA**
> Giải pháp bằng **từ ngữ thường ngày**, không code

### 3️⃣ **DIAGRAM**
> Hình vẽ (ASCII) để nhìn mối quan hệ

### 4️⃣ **LOGIC**
> Pseudo-code hoặc flow (dễ hiểu, bỏ syntax)

### 5️⃣ **NHỚ NHÉ** 🧠
> Một câu catchy để **chốt khái niệm**

### 6️⃣ **VS CÁI KHÁC**
> So sánh nhanh giữa patterns tương tự

### 7️⃣ **VÍ DỤ CODE**
> JavaScript hoặc Python (dễ follow)

---

## Mục tiêu

✅ Hiểu **tại sao** cần pattern (problem)  
✅ Hiểu **ý tưởng** (concept)  
✅ Biết **khi nào** dùng  
✅ Có thể **apply** vào code của bạn  

❌ KHÔNG cần nhớ code C#  
❌ KHÔNG cần học thuộc tên patterns
